A deadpan one-star review of Mondays, filed in earnest against a thing that cannot be fixed.

> Monday arrives every week, on time, with no refund, no unsubscribe button, and no apology. One star — would not recommend this recurring subscription.

`main.py` writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and verifies it byte-for-byte. Run it with `python3 main.py`.
